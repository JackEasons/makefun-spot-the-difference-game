Twin Glasshouse is an original spot-the-difference game: three hand-painted rooms (a botanist's greenhouse, a midnight observatory, a clockmaker's atelier), eight fair-but-sneaky differences in each, a ticking clock, hints, combos, a magnifier lens and synthesized sound — all drawn in code with no borrowed art.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and click a room to begin. Click a difference on either picture (or move the crosshair with the arrow keys and press Enter). H spends a hint, M toggles the magnifier, P pauses.
